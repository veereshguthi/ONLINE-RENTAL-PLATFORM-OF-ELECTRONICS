# CircaTech Electronics Rental Platform

On-demand electronics rental marketplace for MacBook Pros, iPhones, mirrorless cameras, and professional creator equipment.

## Deploying to Render
1. Push this folder to a new GitHub repository.
2. In [Render Dashboard](https://dashboard.render.com), click **New + > Web Service** (or **Static Site**).
3. Connect your repository.
4. Set Build Command: `npm install && npm run build`
5. Set Start Command: `npm run start`
6. Click Deploy!
